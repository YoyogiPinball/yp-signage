# samples — 動作確認用のダミー画像

スライドショーの画像置き場（既定 `~/signage/slides`）が空だと、画面には
「画像なし」という文字だけが出る。正常な動作なのに壊れて見えるので、
最初の1枚としてここの画像を置いて画面を成立させる。

```bash
mkdir -p ~/signage/slides
cp samples/*.jpg ~/signage/slides/
```

| ファイル | 中身 |
|---|---|
| `sample-01-night-blue.jpg` | 濃紺〜暗い青緑のグラデーション |
| `sample-02-amber-fog.jpg` | 琥珀色〜こげ茶の霧 |

どちらも 1080×1920（縦置き想定）。生成 AI（Google Gemini）で作った抽象画像で、
人物・ロゴ・実在の風景を含まない。

> **Note:** 上下が暗く、中央だけ明るいのは意図的。時計・カレンダー・配信予定は
> 画面の上端と下端に白文字で重なるので、そこが明るいと文字が読めなくなる。
> 自分で背景を用意するときも、上下1/4は暗く静かなものを選ぶと失敗しない。
